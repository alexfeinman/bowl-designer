# Wood grain textures

Per-species seamless diffuse maps, downscaled to 512×512. Every species now has a
true-colour photo, so none are tinted at render time.

Five are from **Poly Haven** (https://polyhaven.com), licensed **CC0 1.0 (public
domain)** — free to use, no attribution required (credited here as a courtesy):

| File          | Poly Haven asset         | Used for     |
|---------------|--------------------------|--------------|
| `maple.jpg`   | `white_maple_veneer`     | Hard maple   |
| `walnut.jpg`  | `black_walnut_veneer_01` | Black walnut |
| `cherry.jpg`  | `cherry_veneer`          | Cherry       |
| `oak.jpg`     | `white_oak_veneer`       | White oak    |
| `ash.jpg`     | `ash_veneer`             | Ash          |

Three exotic species have no CC0 match and use textures **supplied by the project
owner** (`padauk.jpg`, `wenge.jpg`, `purpleheart.jpg`). Confirm their licensing is
compatible with how this app is distributed.
